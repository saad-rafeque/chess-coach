The first full release. This update gives the board its feel: wooden sounds, phone vibrations, and a
clear red pulse when a king is in check.

## What's new
- **Board sounds:** every move and capture makes an authentic wooden chess sound, with its own sounds for
  checks, wins and losses. Play, Puzzles and Lessons all sound like a real board. Prefer quiet?
  Settings → Board and coach → Board sounds.
- **Phone vibration:** on Android your own moves give a short buzz, stronger for captures and checks.
  Settings → Board and coach → Phone vibration.
- **Check warning:** when a king is in check its square pulses red, so the danger is impossible to miss.
- **Settings:** two new switches, Board sounds and Phone vibration, both on by default.

## Install
- **Android:** open `ChessCoach-1.0.0-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.0-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.0-amd64.deb`, or
  `chmod +x ChessCoach-1.0.0-x86_64.AppImage && ./ChessCoach-1.0.0-x86_64.AppImage`
