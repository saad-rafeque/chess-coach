A security update: updates are now signed, sign-in is kept in the system keychain, and the
language model is re-checked before every use. No changes to how the app plays.

## What's new
- **Updates are now signed.** Each release's checksums carry the release key's signature, and the app
  refuses to install an update that isn't signed — so a release published without the key (for example
  after a takeover of the GitHub account) can never install itself automatically. The app sends you to
  the release page instead.
- **Update and model downloads stay on their hosts.** Every redirect is checked before the next request
  goes out, so a download can never be led off GitHub or Hugging Face.
- **Your Google sign-in is kept in the system keychain** (Windows DPAPI, Linux keyring, Android Keystore)
  where the operating system encrypts it, with the previous file-based storage as a fallback.
- **The language model is re-checked before every use** (once per app start), so a file swapped in after
  its last check is refused instead of loaded.
- **Linux builds are reproducible.** After every release the CI rebuilds the AppImage, deb and tar.gz
  from the same commit and fails loudly if the hashes do not match what was published — proof that the
  download matches the source. Windows artifacts are built with fixed timestamps so they stay comparable.
- Every release now also ships an SBOM (dependency inventory), and dependencies are scanned for known
  vulnerabilities on every push and pull request.

## Install
- **Android:** open `ChessCoach-1.0.2-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.2-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.2-amd64.deb`, or
  `chmod +x ChessCoach-1.0.2-x86_64.AppImage && ./ChessCoach-1.0.2-x86_64.AppImage`
