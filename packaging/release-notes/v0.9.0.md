Your data in Documents, and a Sync button on Home.

## Where your data lives
- **Windows and Ubuntu:** everything is saved in **Documents → Chess Coach** (`events.jsonl` holds all your
  games, puzzles and lessons; `models` holds the optional language model). Data from earlier versions is
  moved there automatically the first time.
- **Android:** data stays private inside the app. You only need to sign in to sync.

## Sync
- Connect once per device in **Settings → Google Drive sync** with the same Google account
  (saadrafiique@gmail.com). The app creates its hidden folder in your Drive by itself.
- It syncs when the app opens and when you close it. A **Sync** button at the top of Home (and **Sync now**
  in Settings) syncs right away if you ever need it.
- Google asks you to connect again about once a week (the sign-in is in testing mode); nothing is lost.

## Install
- **Android:** open `ChessCoach-0.9.0-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-0.9.0-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `chmod +x ChessCoach-0.9.0-x86_64.AppImage && ./ChessCoach-0.9.0-x86_64.AppImage`
