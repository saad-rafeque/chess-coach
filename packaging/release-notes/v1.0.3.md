Fixes for update and model-download problems players ran into.

## What's new
- **The language model downloads again.** The download could be refused with "download link
  is not secure" when Hugging Face redirected it to one of its short-domain stores; those hosts
  are now recognised.
- **The app tells you about updates.** As soon as an update is found you get the dialog, and the
  home page now keeps an *Update available* notice with an Update button until you install it —
  even if you dismissed the dialog, so nothing needs to be hunted for in Settings.
- **An interrupted install no longer sticks.** If the Android install screen was interrupted
  (screen locked, switched apps), the app now stops waiting after two minutes, shows what happened,
  and one tap starts the update again — no clearing app data needed.
- The release carries the usual signed checksums, SBOM, and rebuild verification for every platform.

## Install
- **Android:** open `ChessCoach-1.0.3-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.3-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.3-amd64.deb`, or
  `chmod +x ChessCoach-1.0.3-x86_64.AppImage && ./ChessCoach-1.0.3-x86_64.AppImage`
