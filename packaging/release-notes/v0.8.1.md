## Sync your devices
- Open **Settings → Google Drive sync → Connect** on each device and sign in with the same Google account
  (saadrafiique@gmail.com is the allowed account).
- Google shows **"Google hasn't verified this app"**: that's expected for a personal app. Click
  **Continue** (or **Advanced → Go to Chess Coach**), then allow access to the app's own folder.
- The page then says "Signed in". Go back to Chess Coach: it syncs right away, and again whenever the app
  opens or closes.
- Only a hidden Chess Coach folder in your Drive is used; the app can't see your other files. It's free:
  no billing, and the file is tiny.
- Because the Google sign-in is in "testing" mode, Google asks you to connect again about once a week.
  When that happens, the Sync card says so: just tap **Connect** again. Nothing is lost.

## Install
- **Android:** open `ChessCoach-0.8.1-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-0.8.1-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `chmod +x ChessCoach-0.8.1-x86_64.AppImage && ./ChessCoach-0.8.1-x86_64.AppImage`
