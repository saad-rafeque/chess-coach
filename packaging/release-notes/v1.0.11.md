Two-player turn and move enhancements, coach hint improvements, macOS styling and window controls, responsive split-screen and picture-in-picture layout, and cross-platform bug fixes across Linux, Windows, and mobile.

## What's new
- **Two-player turn and move flow:** Both sides can freely touch and drag their pieces on the board; interactions smoothly adapt to the side to move without locking to a single side.
- **Coach hints in two-player mode:** Either player can tap Hint at any time. The coach addresses whoever is to move by name ("White: look at your...", "Black: ...") and highlights the best tactical square.
- **Picture-in-picture & split-screen sizing:** Automatic responsive layout and sizing adjustments during split-screen and PiP windows, keeping the board and controls visible without overflow.
- **macOS style & aesthetic polish:** macOS window chrome styling, refined player cards, and enhanced aesthetic fluency.
- **Cross-platform stability & bug fixes:**
  - Resolved Linux and Windows engine pipe buffer deadlocks and crash recovery.
  - Hardened Glicko-2 and FSRS algorithms against division-by-zero and non-finite values.
  - Fixed mobile system back gesture navigation in puzzles, cards, and game bottom sheets.
  - Fixed edge cases in terminal positions, promotion piece counting, and review progress meters.

## Install
- **Android:** open `ChessCoach-1.0.11-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.11-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.11-amd64.deb`, or
  `chmod +x ChessCoach-1.0.11-x86_64.AppImage && ./ChessCoach-1.0.11-x86_64.AppImage`
