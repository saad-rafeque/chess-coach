A proper Ubuntu package, as promised in the plan.

## New
- **Ubuntu .deb:** `ChessCoach-0.9.1-amd64.deb` installs Chess Coach like any other app: it appears in the
  app menu, the dock shows its icon, and `chess-coach` starts it from a terminal. Install with
  `sudo apt install ./ChessCoach-0.9.1-amd64.deb`; later versions install over it.
  Your data stays in **Documents → Chess Coach** and is never removed when uninstalling.
- The AppImage is still attached if you prefer a single file that needs no installation.

## Install
- **Android:** open `ChessCoach-0.9.1-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-0.9.1-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-0.9.1-amd64.deb`, or
  `chmod +x ChessCoach-0.9.1-x86_64.AppImage && ./ChessCoach-0.9.1-x86_64.AppImage`
