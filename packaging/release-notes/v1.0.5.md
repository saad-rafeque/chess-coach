Two players can now play each other on one device, with the coach helping either side.

## What's new
- **Two-player mode:** New game → *Two players* puts two people on one board. Pass the
  device over after each move. Either player can tap **Hint** and the coach suggests what
  to play for the side to move — first which piece to look at, tap again for the move itself.
- Undo takes back exactly the move that was just played, and the verdict names the winner.
  Two-player games stay between you: they are not graded or added to your training history.
- Small update polish: once an install really starts, the old update offer is dropped, and a
  failed background install reports itself instead of leaving the app stuck.

## Install
- **Android:** open `ChessCoach-1.0.5-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.5-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.5-amd64.deb`, or
  `chmod +x ChessCoach-1.0.5-x86_64.AppImage && ./ChessCoach-1.0.5-x86_64.AppImage`
