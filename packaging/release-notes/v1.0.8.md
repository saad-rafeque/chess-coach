A verification release: every platform's rebuild check now passes, and the APK is signed with
the modern v2/v3 schemes only.

## What's new
- **Android rebuild verification completed.** APK signatures embed a random salt, so two builds
  of the same source legitimately differ in the signature bytes. The release now also ships the
  *unsigned* APK: CI rebuilds it from the same commit, requires a bit-identical match, and
  verifies the signature against the release certificate — the same method F-Droid uses. The
  signed APK is what you install; the unsigned one is proof material.
- The APK is now signed with APK Signature Scheme v2/v3 only (v1 is deprecated and added
  nothing for supported Android versions).
- Build-verification steps retry flaky downloads instead of failing the run.

## Install
- **Android:** open `ChessCoach-1.0.8-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.8-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.8-amd64.deb`, or
  `chmod +x ChessCoach-1.0.8-x86_64.AppImage && ./ChessCoach-1.0.8-x86_64.AppImage`
