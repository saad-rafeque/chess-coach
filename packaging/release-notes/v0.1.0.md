First release: play the coach on Android, Windows and Ubuntu.

## What's inside
- Play the coach at any strength from about 400 to full Stockfish 19, as White or Black.
- Training mode: every move graded (best, good, inaccuracy, mistake, blunder) with a short reason and
  the better move on the board; two-step hints; evaluation bar. Real game mode keeps the coach quiet.
- Undo, resign, and your unfinished game is restored when you reopen the app.
- Starter puzzles, lesson outline, Light / Dark / Wooden themes.

## Install
- **Android:** download `ChessCoach-0.1.0-android-arm64.apk`, open it, and allow installing from this source.
- **Windows:** run `ChessCoach-0.1.0-Setup.exe`. Windows SmartScreen may warn about an unknown publisher:
  choose *More info → Run anyway*. A portable `.zip` is also attached.
- **Ubuntu:** download `ChessCoach-0.1.0-x86_64.AppImage`, then
  `chmod +x ChessCoach-0.1.0-x86_64.AppImage && ./ChessCoach-0.1.0-x86_64.AppImage`.
