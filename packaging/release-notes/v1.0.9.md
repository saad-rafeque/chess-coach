Every platform's rebuild check now passes: the first release where all published artifacts are
proven to be reproducible.

## What's new
- **Windows builds are reproducible.** The Windows binaries no longer embed the link time
  (`/Brepro`), so two clean builds of the same source are bit-identical — verified file by file.
  After this release, CI rebuilds the Setup.exe and zip and requires their hashes to match the
  published checksums.
- **Android rebuild verification completed.** APK signatures embed a random salt, so two builds
  of the same source legitimately differ in the signature bytes. The rebuild check compares every
  file inside the APK (name, size, CRC) and verifies the rebuilt signature against the release
  certificate — the same method F-Droid uses.
- Linux rebuild verification has passed since v1.0.2 and keeps passing.
- Build-verification steps retry flaky downloads instead of failing the run.

## Install
- **Android:** open `ChessCoach-1.0.9-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.9-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.9-amd64.deb`, or
  `chmod +x ChessCoach-1.0.9-x86_64.AppImage && ./ChessCoach-1.0.9-x86_64.AppImage`
