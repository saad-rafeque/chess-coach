The look-and-feel update: the board now owns the screen, the pieces are the classic clearly-shaped set,
and the sounds are new.

## What's new
- **The board is the star:** on phones it sits centred on the screen, edge to edge, and the coach's latest
  message stays visible right under it (tap the message to open the full panel). On the desktop the side
  panel can be hidden with the dock button, so the board takes the whole window.
- **Clear pieces:** every theme now starts with the classic set of well-defined piece shapes (the same
  family as chess.com and Lichess). The ten 3D sets are still in Settings → Board and pieces.
- **New sounds:** crisp and modern move and capture taps, a soft bell for check, a gentle chime when you
  win, a calm two-note drop when you lose. Settings → Board and coach → Board sounds.
- **Updates work again:** the repository is public, so the app can now see new releases and offer updates
  with the usual checksum checks.

## Install
- **Android:** open `ChessCoach-1.0.1-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-1.0.1-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-1.0.1-amd64.deb`, or
  `chmod +x ChessCoach-1.0.1-x86_64.AppImage && ./ChessCoach-1.0.1-x86_64.AppImage`
