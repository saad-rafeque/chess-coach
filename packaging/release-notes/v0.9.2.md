A security update. Nothing changes in how you use the app; it is just harder to attack.

## Safer
- **Google sign-in:** the app now only accepts Google's own answer to its sign-in. Other programs or web
  pages on your computer can no longer slip in a fake answer or cancel your sign-in. If you untick the
  Drive permission on Google's page, the app tells you instead of failing later.
- **Sign-in storage:** the Google sign-in is kept in its own file that only your user account can read, no
  longer in the general settings file. Android excludes the app from phone backups and transfers, so the
  sign-in never leaves the phone.
- **Synced data is checked:** every game, puzzle, lesson and review card read from Google Drive or from
  the data folder is checked before use (legal moves, sensible numbers). A damaged or tampered file can no
  longer crash a screen or spoil your ratings; bad entries are skipped and the rest still loads. Oversized
  sync files are refused.
- **Language model:** the downloaded model is checked again whenever the file changes, so a replaced file
  is never loaded. Downloads never follow a link off HTTPS.
- **Builds:** the engine, the packaging tool and the llama.cpp runtime are pinned to known checksums, the release key is
  required, and the release lists SHA-256 checksums (`SHA256SUMS.txt`) of every file.

## Install
- **Android:** open `ChessCoach-0.9.2-android-arm64.apk` and allow installing from this source. It installs
  over earlier versions and keeps your data.
- **Windows:** run `ChessCoach-0.9.2-Setup.exe`. If SmartScreen warns about an unknown publisher,
  choose *More info → Run anyway*. A portable `.zip` is attached too.
- **Ubuntu:** `sudo apt install ./ChessCoach-0.9.2-amd64.deb`, or
  `chmod +x ChessCoach-0.9.2-x86_64.AppImage && ./ChessCoach-0.9.2-x86_64.AppImage`
