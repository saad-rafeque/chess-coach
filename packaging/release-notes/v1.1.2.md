# Chess Coach 1.1.2

- A calmer Home: jump into a game, take a puzzle break or continue your lesson.
  Detailed progress and training choices are still available when you want them.
- Improved split-screen, narrow-window and large-text layouts, including Lessons,
  coach names and New-game controls. PiP has been removed to focus on split-screen.
- Correct threefold repetition, daylight-saving streaks and invalid imported
  review suggestions.
- More reliable Google Drive reconnection and account switching, plus update
  retry and Linux launcher-icon fixes.
- All existing themes, board looks and piece sets are retained.

Android, Linux and Windows packages are built from the same source. Security,
tests and independent rebuild comparisons must pass before publication.

This release includes the work prepared for 1.1.1, which was blocked before
publication by a nondeterministic Flutter asset manifest. Image variants now
have a stable build order; exact APK payload and signing checks remain enforced.
