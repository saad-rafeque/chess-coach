## Additional findings and release boundary

- Learning boards now share the centered portrait layout; short sheets retain full instructions and next/finish actions.
- Captured-piece bars reproduced the user's exact 1 px overflow; constrained text now fits the reserved bar height.
- Added turn-aware Redo, visible offline hints, explicit hint-busy state and guarded Play hint.
- Added native PiP Undo / Hint / Play hint actions. Native board taps require returning fullscreen.
- Corrected Android-only OAuth setup detection and exposed a clear unavailable-build explanation.
- Drive snapshots merge each device's updates; old clients must update for two-way sync.
- Independent review reproduced lost concurrent history writes and damaged-line recovery bugs; fixed with serialized append and per-line validation.
- Independent review identified cross-account access-token reuse; account identity and generation guards added.
- Original themes retained; six color themes and three interface styles covered by a rendering/persistence matrix.

On user request, all subagents were stopped and work moved to release preparation.
The independent audit is therefore **partial**, not an exhaustive completion certificate.
Android profile compilation succeeded. USB device native PiP action testing and
measured frame-time profiling were not completed before this release request.
